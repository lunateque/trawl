# trawl step 7: TUI

**Goal:** `trawl tui` — a Textual app to watch the queue live and make every manual decision the spec gives the owner, without leaving the terminal.

**Spec:** `docs/specs/2026-11-23-trawl-design.md` — Интерфейс (TUI), Данные (transitions: `skipped`, `pick` with pinned candidate, manual acceptance of an AcoustID-rejected file `verified_by=manual`), Исполнение (lock: TUI embeds the runner when it gets the lock, otherwise observer mode). The spec wins; report conflicts. Read the existing code first; reuse `db/queue.py`, `repo`, `states.transition`, `runner/run.py`, `runner/watch.py`.

**Gate:** `uv run ruff check` · `uv run ruff format --check` · `uv run pyright` · `uv run pytest -q`

## Layout

One screen, keyboard first, mouse optional.

```
┌ trawl ─ runner: running (pid 1234) │ library D:/music │ 12:04 ───────────────────────────┐
│ Queue                │ Sources                                                        │
│ planned     120      │ ytmusic   active   2/2 downloading   ok 41  rej 3              │
│ searching     4      │ soulseek  paused 1h12m  "connection refused"                   │
│ fetched…tagged 6     │ local     idle                                                 │
│ done       3201      ├─────────────────────────────────────────────────────────────────┤
│ missing      57      │ Events (newest first)                                          │
│ skipped       9      │ 12:03 done      Кино — Группа крови / 03 Война (flac, acoustid)│
│ unresolved   14      │ 12:03 rejected  … reason                                        │
├──────────────────────┴─────────────────────────────────────────────────────────────────┤
│ Needs you: [Missing 57] [Rejected 5] [Unresolved 14]                                    │
│ table of the selected list                                                             │
└ r retry  s skip  p pick  a accept  l link  e explain  w watch on/off  q quit ───────────┘
```

- Header: runner state (embedded running / observer with the holder pid / stopped), library root, clock.
- Queue counts and Sources panel refresh every 2 s from the DB (`source_state`, attempts of the last hour, active downloads from an in-memory progress map when embedded; in observer mode show DB-derived info only).
- Events: last 200 transitions and attempts (read from `attempts` plus a small `events` view/table if needed — a migration is fine).
- "Needs you" tabs:
  - **Missing**: tracks in `missing` with release, last attempts summary.
  - **Rejected**: tracks whose latest attempt is `rejected_verify` with the staged file still present, or pinned candidates waiting for the owner (spec: an AcoustID rejection of a picked candidate is shown, not silently dropped).
  - **Unresolved**: rows of `unresolved`.

## Actions

| Key | Where | Effect |
|---|---|---|
| `e` | any row | explain modal (same content as `trawl explain`) |
| `r` | Missing | `missing → planned` |
| `s` | Missing, Rejected, any track | `→ skipped` |
| `p` | Missing, Rejected | candidates modal: lists candidates from the last search (store them: attempts already have `candidate_ref` and `score`; add what the modal needs) with score and reject reason; Enter pins one (`pinned_candidate`, `→ searching`); `u` pastes a YouTube/YouTube Music URL or a local path |
| `a` | Rejected | accept the staged file as is: `verified_by=manual`, continue to tagging; confirm dialog shows the AcoustID result vs the plan |
| `l` | Unresolved | input a MusicBrainz link → `trawl link` logic |
| `w` | header | embedded mode only: toggle watch loop (default on when embedded) |
| `q` | — | quit; embedded runner finishes the current transition, releases the lock |

All writes go through `states.transition` (conditional) so the TUI and an external runner never overwrite each other; a failed transition shows a toast "already changed by the runner" and refreshes.

## Embedded runner

- On start try the lock. Got it → start `runner/watch.py` loop in a Textual worker (async), feed progress events through a queue into the Events panel. Not got it → observer mode; actions still write to the DB.
- Ctrl+C / `q` → cancel cleanly like `run --watch`.

## Tests

- Textual `App.run_test()` pilot tests with a temp DB seeded with tracks in every state, fake runner deps (no network, no tools):
  - counts render; switching tabs; `r` moves a missing track to planned; `s` skips; `p` pins a candidate and the DB shows `pinned_candidate`; `a` on a rejected track sets `verified_by=manual`; `l` creates a want and removes the unresolved row; observer mode when the lock is held by another process (hold it in the test); a transition conflict shows the toast.
- Snapshot tests are not required.
